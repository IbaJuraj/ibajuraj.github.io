# IbaJuraj Application Standard

Tento priečinok obsahuje spoločný štandard aplikácií IbaJuraj.

- `IBAJURAJ_APPLICATION_STANDARD.md` – hlavný autoritatívny dokument,
- `SUPPORT_AND_LINKS.md` – jednotné odkazy webu, podpory, súkromia a Telegramu,
- `GOVERNANCE.md` – pravidlá verzionovania a zmien,
- `CHANGELOG.md` – história štandardu.

Produktové pravidlá zostávajú v repozitároch jednotlivých aplikácií. Aplikácia má v `APP_STANDARD_ADOPTION.md` uviesť použitú verziu a výnimky.
